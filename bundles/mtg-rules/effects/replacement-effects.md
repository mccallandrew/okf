# Definition

A **replacement effect** watches for an event and replaces it with a different event ("instead," "skip," "as … enters," etc.).[^cr-614]

# Rules

* Replacement effects apply as the event would happen; they do not use the stack.
* Self-replacement effects and continuous replacement from static abilities are common.
* If multiple replacements apply, the affected player or controller of the affected object usually chooses the order.
* Prevention effects are a related category; see [Prevention Effects](/effects/prevention-effects.md).

# Loops and self-replacement

* A **self-replacement** modifies an event caused by the same object/effect (for example “as this enters” replacements). CR 616 often applies self-replacements before other replacements controlled by another player.
* If replacements would cause an infinite loop with no choices that break it, the game is a draw under the golden rules — players must choose differently when choices exist to avoid a loop.
* After one replacement applies, the modified event may be replaced again by other applicable effects.
