# Definition

A **one-shot effect** does something once when it applies — deal damage, destroy a permanent, draw cards, create tokens — and then is finished. It contrasts with [continuous effects](/effects/continuous-effects.md), which last for a duration.[^cr-610]

# Rules

* Most resolving spells and abilities produce one-shot effects (possibly several in sequence).
* A one-shot effect can create a continuous effect (for example "target creature gets +2/+2 until end of turn"); the continuous part then lasts independently.
* [Replacement](/effects/replacement-effects.md) and [prevention](/effects/prevention-effects.md) effects can modify the events a one-shot effect would cause.
* After a one-shot effect has happened, it does not "stick around" as a lasting modification unless it explicitly created a continuous effect or other lasting game object.
