# Definition

A **continuous effect** modifies characteristics or the game rules for some duration (or indefinitely while a static ability applies).[^cr-611]

# Rules

* Continuous effects come from static abilities, resolving spells/abilities that create lasting changes, or counters in some cases.
* Interaction among continuous effects is handled by the [layer system](/effects/layers.md).
* "Until end of turn" effects end during cleanup.
