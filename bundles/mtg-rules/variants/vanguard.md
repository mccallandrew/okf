# Definition

**Vanguard** is a casual variant in which each player uses a vanguard card that modifies starting life and hand size.[^cr-902]

# Rules

* Each player chooses a vanguard card before the game; it begins in the command zone.
* Hand and life modifiers apply as the vanguard card specifies.
