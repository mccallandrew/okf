# Definition

**Casual variants** (CR 9xx) are optional game styles that add supplemental zones, cards, or rules not used in traditional Constructed/Limited play. The CR section is explicitly not comprehensive.[^cr-900]

# Rules

* Variants here typically use extra implements in the [command zone](/zones/command.md) (planes, schemes, commanders, and so on).[^cr-900]
* Many casual variants specify a default multiplayer setup (often Free-for-All and/or shared team turns). See [Multiplayer Overview](/multiplayer/multiplayer-overview.md).
* **Two-Headed Giant** is a multiplayer *variant* under **CR 810**, not CR 9xx — documented at [Two-Headed Giant](/multiplayer/two-headed-giant.md).
* **Commander** is CR **903** (casual variants) but lives in this bundle under [Commander Overview](/multiplayer/commander-overview.md) because it is the common social multiplayer format.
* Other CR 9xx entries include Vanguard (902) and Conspiracy Draft (905); this hub seeds Planechase, Archenemy, and a light Limited overview only.
