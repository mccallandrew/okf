# Definition

**Conspiracy Draft** is a limited casual variant that includes conspiracy cards with draft and game abilities.[^cr-905]

# Rules

* Conspiracies may be drafted and begin outside the main deck / in the command zone as specified.
* Some conspiracies have hidden agendas named as the game starts.
