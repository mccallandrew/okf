# Definition

**Linked abilities** are abilities on the same object that are connected so information from one (often cards exiled) is used by another.[^cr-607]

# Rules

* An ability can be linked to one or more other abilities on the same object.
* If an object gains an ability that would be linked, linkage follows CR 607.
* Common on exile-and-cast or imprint-style designs.
