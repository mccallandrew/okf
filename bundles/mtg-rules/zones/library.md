# Definition

Each player has a **library** — a face-down, ordered zone that holds that player's remaining deck.[^cr-401]

# Rules

* Cards in a library have no characteristics unless an effect reveals them or looks at them.
* Drawing moves the top card of the library into the hand.
* Searching the library usually requires shuffling afterward unless otherwise stated.
* A player who must draw from an empty library loses the game.
