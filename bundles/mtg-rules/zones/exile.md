# Definition

**Exile** is a public zone used for objects that are removed from the game without going to a graveyard.[^cr-406]

# Rules

* Exiled cards are face up by default unless an effect exiles them face down.
* Exile is not the graveyard; many "dies" and graveyard triggers do not apply.
* Effects may exile temporarily and return the object later.
* Tokens that would be exiled cease to exist.
