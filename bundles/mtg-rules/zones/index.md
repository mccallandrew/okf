# Zones

* [Zones](zone.md) - Where objects live during a Magic game.
* [Library](library.md) - A player's face-down deck zone.
* [Hand](hand.md) - A player's private zone for cards drawn but not yet played.
* [Battlefield](battlefield.md) - The shared public zone where permanents exist.
* [Graveyard](graveyard.md) - A player's public discard pile for cards that have left play.
* [Stack](stack.md) - The shared zone where spells and abilities wait to resolve.
* [Exile](exile.md) - A public zone for objects removed from the game without using the graveyard.
* [Command](command.md) - Zone for objects that start outside the main deck, such as emblems and commanders.
* [Ante](ante.md) - Obsolete zone used only when playing for keeps; cards are wagered from the library.
