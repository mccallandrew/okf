# Foundations

* [Golden Rules](golden-rules.md) - The four Magic Golden Rules that override and resolve conflicts.
* [Players](players.md) - Who participates in a game and their roles.
* [Colors](colors.md) - The five Magic colors and how an object's color is determined.
* [Objects](objects.md) - The game's countable game pieces and how they exist.
* [Characteristics](characteristics.md) - The values that describe an object — name, cost, color, types, abilities, P/T, and more.
* [Permanents](permanents.md) - Objects on the battlefield.
* [Spells](spells.md) - Cards and copies on the stack awaiting resolution.
* [Abilities](abilities.md) - Activated, triggered, and static abilities.
* [Mana Abilities](mana-abilities.md) - Abilities that produce mana and resolve without using the stack.
* [Mana](mana.md) - Mana, mana pools, and paying mana costs.
* [Costs](costs.md) - What must be paid to cast spells or activate abilities.
* [Counters](counters.md) - Markers placed on objects or players that modify characteristics or track values.
* [Drawing a Card](drawing-a-card.md) - Moving the top card of a library into its owner's hand, and what counts as a draw.
* [Emblems](emblems.md) - Command-zone objects created by effects that give a player ongoing abilities.
* [Summoning Sickness](summoning-sickness.md) - Restriction preventing newly controlled creatures from attacking or using tap/untap abilities.
* [Attachments](attachments.md) - How Auras and Equipment attach to, move among, and fall off permanents.
* [Copying](copying.md) - Creating a copy of an object or spell and which values the copy inherits.
* [State-Based Actions](state-based-actions.md) - Automatic checks that clean illegal or losing game states without using the stack.
* [Legend Rule](legend-rule.md) - State-based action that limits legendary permanents with the same name under one player's control.
* [Starting the Game](starting-the-game.md) - How a game begins — life totals, opening hands, and mulligans.
* [Winning and Losing](winning-and-losing.md) - How a game ends — win and lose conditions, including drawing from an empty library.
* [Parts of a Card](parts-of-a-card.md) - The printed parts of a Magic card and which ones are characteristics.
* [Mana Symbols and Numbers](mana-symbols.md) - Mana symbols, numeric placeholders like X, and related symbols in costs and rules text.
* [Turn-Based Actions](turn-based-actions.md) - Game actions the game performs automatically at specified points in the turn.
* [Flipping a Coin](coin-flips.md) - Rules for coin flips as randomizing instructions in spells and abilities.
* [Rolling a Die](die-rolls.md) - Rules for rolling dice, planar dice, and numbered outcomes.
* [Controlling Another Player](controlling-another-player.md) - Effects that let a player control another player during that player's next turn.
* [Ending Turns and Phases](ending-turns-and-phases.md) - Effects that end the turn or phase, skipping remaining steps.
* [The Monarch](the-monarch.md) - Designation a player can have that draws a card in the end step and can be taken in combat.
* [The Initiative](the-initiative.md) - Designation involving the Undercity dungeon and venture benefits.
* [Restarting the Game](restarting-the-game.md) - Effects that end the current game and start a new game with special setup.
* [Rad Counters](rad-counters.md) - Counters on players that mill and cause life loss in the end step / SBAs.
* [Subgames](subgames.md) - Games created by effects (for example Shahrazad) inside another game.
* [Merging with Permanents](merging-with-permanents.md) - Rules for merged permanents (meld-like stacks of cards representing one permanent).
* [Day and Night](day-and-night.md) - Designations day and night that transform daybound/nightbound permanents.
* [Taking Shortcuts](taking-shortcuts.md) - Tournament-style explicit shortcuts for proposing out-of-order sequences.
* [Handling Illegal Actions](handling-illegal-actions.md) - What happens if a player attempts an illegal action.
