# Definition

An **emblem** is a marker in the [command zone](/zones/command.md) that a player gets from certain effects (often planeswalker ultimates). It is not a card or permanent; it only provides the abilities stated by the effect that created it.[^cr-114]

# Rules

* Emblems have no characteristics other than the abilities granted by their creating effect.
* An emblem is not a permanent, cannot be targeted as a permanent, and cannot be destroyed.
* Emblems are not cards; card-affecting effects do not affect them.
* Once created, an emblem remains for the rest of the game unless an effect specifically removes it (rare).
* Emblems are [objects](/foundations/objects.md) that live only in the command zone.
