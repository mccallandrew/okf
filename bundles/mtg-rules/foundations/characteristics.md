# Definition

**Characteristics** are the values that describe an [object](/foundations/objects.md): what it is called, costs, colors, types, text, and numeric stats. Effects that "set," "change," or copy characteristics operate on this list.[^cr-109][^cr-200]

# Core characteristics

| Characteristic | Notes |
|----------------|-------|
| Name | Used for legend rule, naming cards, and many effects |
| Mana cost | Determines mana value; contributes to color |
| Color | Derived from mana cost, color indicator, or effects |
| Card type(s) | Creature, instant, artifact, and so on |
| Subtype(s) | e.g., Goblin, Aura, Equipment, Forest |
| Supertype(s) | e.g., Legendary, Basic, Snow |
| Rules text / abilities | What the object does |
| Power / toughness | Creatures (and some other objects while they are creatures) |
| Loyalty | [Planeswalkers](/card-types/planeswalker.md) |
| Defense | [Battles](/card-types/battle.md) |

Hand and life modifiers (Vanguard-style) are also characteristics when present.

# Rules

* Characteristics depend on zone: a card in a hidden zone generally has no characteristics visible to opponents unless revealed.
* Continuous effects, [counters](/foundations/counters.md), [attachments](/foundations/attachments.md), and [copy](/foundations/copying.md) effects can change characteristics; order is governed by [layers](/effects/layers.md).
* Mana value is derived from mana cost (with special cases for split, aftermath, and similar cards).
* Tokens and copies have characteristics defined by the effect that created them.
