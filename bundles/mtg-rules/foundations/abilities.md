# Definition

An **ability** is text that an object has which affects the game. Abilities are activated, triggered, or static.[^cr-113]

# Kinds

| Kind | Form | How it works |
|------|------|----------------|
| Activated | `Cost: Effect` | Player activates; goes on the stack (except mana abilities). |
| Triggered | `When/Whenever/At …, effect` | Triggers when event occurs; goes on the stack next time a player would receive priority. |
| Static | Continuous text | Creates continuous effects; does not use the stack. |
