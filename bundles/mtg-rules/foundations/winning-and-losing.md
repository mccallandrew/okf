# Definition

A game ends when a player **wins** or all remaining opponents have **lost**. Most lose conditions are checked as [state-based actions](/foundations/state-based-actions.md); some effects say a player wins or loses immediately.[^cr-104]

# Lose conditions

Common ways a player loses:

* Having 0 or less [life](/combat/life.md) (SBA)
* Attempting to draw a card from an empty [library](/zones/library.md) (SBA) — the attempt is what matters; an empty library alone is fine
* Receiving ten or more poison counters (SBA)
* Conceding
* An effect that says the player loses the game

# Win conditions

* Usually a player wins when all opponents have lost.
* Some effects say a player wins the game directly (those take effect when stated, subject to the [Golden Rules](/foundations/golden-rules.md)).
* If all remaining players lose simultaneously, the game is a draw.
