# Definition

**Turn-based actions** are actions the game takes automatically at certain points (untap, draw, combat damage assignment, cleanup discard, and so on).[^cr-703]

# Rules

* They do not use the stack.
* Players usually do not receive priority during a turn-based action.
* Distinct from state-based actions, which check continuously whenever a player would get priority.
