# Definition

A **counter** is a marker placed on an object or player. Counters are not objects themselves. This concept is about game markers — not the keyword action of countering a spell on the [stack](/zones/stack.md).[^cr-122]

# Rules

* Counters stay on an object as it moves only if an effect says so; otherwise they are removed when the object changes zones.
* If an object has both +1/+1 and −1/−1 counters, they cancel in pairs as a [state-based action](/foundations/state-based-actions.md).
* Adding or removing counters is usually instructed by spells or abilities; some enter-the-battlefield replacements put counters on as an object arrives.

# Common kinds

| Kind | Typical use |
|------|-------------|
| +1/+1 / −1/−1 | Modify a creature's power and toughness |
| Loyalty | Track a [planeswalker](/card-types/planeswalker.md)'s loyalty |
| Defense | Track a [battle](/card-types/battle.md)'s defense |
| Keyword counters | Grant keyword abilities (e.g., flying, lifelink) while present |
| Charge, time, verse, etc. | Track progress for specific card mechanics |
