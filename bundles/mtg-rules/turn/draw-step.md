# Definition

In the **draw step**, the active player draws a card (except on the first turn of the game for the starting player, in two-player games). Then players receive priority.[^cr-504]

# Rules

* The draw is a turn-based action at the start of the step.
* "At the beginning of your draw step" triggers happen before the draw in some cases — check CR for exact order with replacement effects.
* Drawing from an empty library causes a loss.
