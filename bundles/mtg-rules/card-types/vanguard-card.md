# Definition

**Vanguard Card** — A card type that modifies starting hand size and life via hand and life modifiers.[^cr-313]

# Rules

* Vanguard cards begin in the command zone and apply their hand/life modifiers.
* Distinct from the Vanguard casual variant rules that use them.
