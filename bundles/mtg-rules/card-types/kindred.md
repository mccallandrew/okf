# Definition

**Kindred** (formerly tribal) is a card type that appears with another card type and allows creature types on noncreature cards (for example, "Kindred Instant — Goblin").[^cr-308]

# Rules

* Kindred is not itself a permanent type that stays alone; it pairs with Instant, Sorcery, Artifact, Enchantment, etc.
* Creature types on kindred cards matter for type-caring effects ("Goblin spells," lords, etc.).
* Older cards may still say "Tribal" in Oracle text updated to Kindred.
