# Card Types

* [Artifact](artifact.md) - Permanent type representing magical items and constructs.
* [Equipment](equipment.md) - Artifact subtype attached to creatures with equip; stays on the battlefield if the creature leaves.
* [Vehicle](vehicle.md) - Artifact subtype that becomes an artifact creature when crewed.
* [Creature](creature.md) - Permanent type that can attack and block.
* [Enchantment](enchantment.md) - Permanent type representing persistent magical effects.
* [Aura](aura.md) - Enchantment subtype that enters attached to an object or player via enchant.
* [Saga](saga.md) - Enchantment subtype that advances with lore counters and chapter abilities, then is sacrificed.
* [Land](land.md) - Permanent type primarily used to produce mana; played as a special action.
* [Planeswalker](planeswalker.md) - Permanent type with loyalty that uses loyalty abilities.
* [Battle](battle.md) - Permanent type with defense that can be attacked; often sieges.
* [Instant](instant.md) - Nonpermanent spell type that can be cast any time you have priority.
* [Sorcery](sorcery.md) - Nonpermanent spell type normally cast only during your main phase with an empty stack.
* [Kindred](kindred.md) - Supertype formerly called tribal — appears with another card type and creature types.
* [Token](token.md) - Permanents created by effects rather than by resolving card spells.
* [Double-Faced Cards](double-faced-cards.md) - Cards with two faces; transforming and modal double-faced cards.
* [Adventure](adventure.md) - Adventurer cards with a permanent half and a castable Adventure spell on the same card.
* [Split Cards](split-cards.md) - Cards with two halves; cast one half (or fuse both), with combined characteristics off the stack.
* [Face-Down Spells and Permanents](face-down.md) - Rules for casting and controlling objects face down (Morph, Disguise, Manifest, and similar).
* [Dungeon](dungeon.md) - A card type representing a multi-room venture path in the command zone.
* [Plane](plane.md) - A planar card used in Planechase, kept in the command zone.
* [Phenomenon](phenomenon.md) - A planar-deck card in Planechase that resolves an effect then is replaced.
* [Scheme](scheme.md) - An Archenemy card type used from a scheme deck in the command zone.
* [Vanguard Card](vanguard-card.md) - A card type that modifies starting hand size and life via hand and life modifiers.
* [Conspiracy](conspiracy.md) - A Conspiracy Draft card type that begins outside the game / in the command zone.
* [Flip Cards](flip-cards.md) - Cards with two sets of characteristics stacked vertically; flipping turns the card 180°.
* [Leveler Cards](leveler-cards.md) - Creatures with level up that gain abilities and P/T as level counters accumulate.
* [Class Cards](class-cards.md) - Enchantments with class levels advanced by paying chapter-like costs.
* [Attraction Cards](attraction-cards.md) - Un-set / Attractions cards visited with ticket counters in Limited/Un-games.
* [Prototype Cards](prototype-cards.md) - Cards with an alternate prototype casting option granting different characteristics.
* [Case Cards](case-cards.md) - Enchantments that solve when a condition is met and then unlock a later ability.
* [Omen Cards](omen-cards.md) - Cards with an Omen spell face that can be cast similarly to Adventures.
* [Station Cards](station-cards.md) - Permanents that use the station keyword to accumulate charge counters for abilities.
* [Preparation Cards](preparation-cards.md) - Cards that can be prepared (set aside) and cast later under special rules.
* [Meld Cards](meld-cards.md) - Pairs of cards that can exile and return as a single melded permanent.
