# Definition

A **token** is a permanent created by an effect (or rule), not by resolving a card spell from a zone. Tokens are permanents while on the battlefield.[^cr-111]

# Rules

* If a token would leave the battlefield and go to any other zone, it ceases to exist.
* Tokens can copy characteristics of cards or be defined by the creating effect.
* Token cards used as reminders are not the same as the game object once the token leaves play.
