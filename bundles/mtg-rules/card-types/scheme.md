# Definition

**Scheme** — An Archenemy card type used from a scheme deck in the command zone.[^cr-314]

# Rules

* Schemes may be ongoing or one-shot; abandoning turns an ongoing scheme face down.
* The archenemy sets schemes in motion as a turn-based action.
