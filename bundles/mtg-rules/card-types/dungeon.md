# Definition

**Dungeon** — A card type representing a multi-room venture path in the command zone.[^cr-309]

# Rules

* Dungeons are not permanents; they usually reside in the command zone while being ventured.
* Venture into the dungeon and related keyword actions interact with dungeon rooms.
