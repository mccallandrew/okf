# Definition

**Commander** (CR 903) is a casual variant — listed under CR 9xx — that is the default social multiplayer format for many groups. Each deck is led by a designated legendary commander that begins in the [command zone](/zones/command.md).[^cr-903]

# Rules

* Default multiplayer setup is Free-for-All with attack multiple players and without limited range of influence.[^cr-903]
* The commander is a legendary creature, Vehicle, or Spacecraft with a power/toughness box; the designation is an attribute of the card and persists across zones.[^cr-903]
* **Color identity** (mana symbols in cost and rules text, plus color indicator / characteristic-defining color) restricts which cards may be in the deck.[^cr-903]
* Deck size is exactly **100** cards including the commander (singleton except basic lands, with other named exceptions in the full CR).[^cr-903]
* Each player starts at **40** life; the commander starts face up in the command zone.[^cr-903]
* Casting a commander from the command zone costs an additional **{2}** for each previous time its owner has cast it from that zone that game (**commander tax**).[^cr-903]
* If a commander would go to the graveyard or exile, its owner may return it to the command zone as a state-based action.[^cr-903]
* A player dealt **21 or more combat damage** by the same commander over the course of the game loses (commander damage).[^cr-903]

# Deck construction and partners

* Singleton deck of 100 cards including the commander; basic lands and other CR-listed exceptions may repeat.
* **Color identity** includes mana symbols in the commander’s mana cost and rules text (and color indicator / characteristic-defining color). Every card in the deck must be within that identity.
* **Partner**, **partner with**, **choose a Background**, and related partner abilities can allow two cards to be your commanders; both begin in the command zone and deck size remains 100 including both. See [Partner](/keywords/partner.md).
* Other commander-related keywords (Companion as an outside-game card, and so on) follow their own CR sections while still obeying Commander deck rules where applicable.
