# Definition

**Activated Ability** — A kind of ability.[^cr-glossary]

# Rules

* A kind of ability.
* Activated abilities are written as “[Cost]: [Effect.] [Activation instructions (if any).]” See rule 113, “Abilities,” and rule 602, “Activating Activated Abilities.”
