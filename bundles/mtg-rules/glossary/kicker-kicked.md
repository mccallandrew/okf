# Definition

**Kicker, Kicked** — Kicker is a keyword ability that represents an optional additional cost.[^cr-glossary]

# Rules

* Kicker is a keyword ability that represents an optional additional cost.
* A spell has been kicked if its controller declared the intention to pay any or all of its kicker costs.
