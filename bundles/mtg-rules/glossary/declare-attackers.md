# Definition

**Declare Attackers** — To choose a set of creatures that will attack, declare whether each creature is attacking the defending player or a planeswalker that player controls, and pay any costs…[^cr-glossary]

# Rules

* To choose a set of creatures that will attack, declare whether each creature is attacking the defending player or a planeswalker that player controls, and pay any costs required to allow those creatures to attack.
* See rule 508.1.
