# Definition

**Map** — A Map token is a colorless Map artifact token with “{1}, {T}, Sacrifice this token: Target creature you control explores.[^cr-glossary]

# Rules

* A Map token is a colorless Map artifact token with “{1}, {T}, Sacrifice this token: Target creature you control explores.
* Activate only as a sorcery.” See rule 701.44, “Explore.” For more information about predefined tokens, see rule 111.10.
