# Definition

**Pass in Succession** — All players “pass in succession” if each player in the game (starting with any one of them) opts not to take an action upon receiving priority.[^cr-glossary]

# Rules

* All players “pass in succession” if each player in the game (starting with any one of them) opts not to take an action upon receiving priority.
* See rule 117, “Timing and Priority.”
