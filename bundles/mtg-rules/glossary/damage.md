# Definition

**Damage** — Objects can deal “damage” to creatures, planeswalkers, and players.[^cr-glossary]

# Rules

* Objects can deal “damage” to creatures, planeswalkers, and players.
* This is generally detrimental to the object or player that receives that damage.
