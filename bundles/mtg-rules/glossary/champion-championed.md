# Definition

**Champion, Championed** — “Champion” is a keyword ability that lets one creature temporarily replace another.[^cr-glossary]

# Rules

* “Champion” is a keyword ability that lets one creature temporarily replace another.
* A permanent is “championed” by another permanent if the latter exiles the former as the direct result of a champion ability.
