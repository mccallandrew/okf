# Definition

**Powerstone Token** — A Powerstone token is a colorless artifact token with “{T}: Add {C}.[^cr-glossary]

# Rules

* A Powerstone token is a colorless artifact token with “{T}: Add {C}.
* This mana can’t be spent to cast a nonartifact spell.” For more information about predefined tokens, see rule 111.10.
