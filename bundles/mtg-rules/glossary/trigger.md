# Definition

**Trigger** — Whenever a game event or game state matches a triggered ability’s trigger event, that ability automatically “triggers.” That means its controller puts it on the stack the next…[^cr-glossary]

# Rules

* Whenever a game event or game state matches a triggered ability’s trigger event, that ability automatically “triggers.” That means its controller puts it on the stack the next time a player would receive priority.
* See rule 603, “Handling Triggered Abilities.”
