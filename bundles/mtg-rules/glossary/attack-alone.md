# Definition

**Attack Alone** — A creature “attacks alone” if it’s the only creature declared as an attacker during the declare attackers step.[^cr-glossary]

# Rules

* A creature “attacks alone” if it’s the only creature declared as an attacker during the declare attackers step.
* A creature “is attacking alone” if it’s attacking but no other creatures are.
