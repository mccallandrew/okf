# Definition

**Airbend** — A keyword action that exiles one or more permanents and/or spells.[^cr-glossary]

# Rules

* A keyword action that exiles one or more permanents and/or spells.
* The owner of each card exiled with airbend may cast it from exile by paying {2} rather than paying its mana cost.
