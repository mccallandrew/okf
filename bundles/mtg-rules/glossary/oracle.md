# Definition

**Oracle** — The reference that contains the up-to-date wordings (in English) for all tournament-legal cards.[^cr-glossary]

# Rules

* The reference that contains the up-to-date wordings (in English) for all tournament-legal cards.
* A card’s Oracle text can be found using the Gatherer card database at Gatherer.Wizards.com.
