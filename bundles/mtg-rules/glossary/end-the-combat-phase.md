# Definition

**End the Combat Phase** — To “end the combat phase” as the result of an effect is to perform an expedited process that skips everything else that would happen that phase.[^cr-glossary]

# Rules

* To “end the combat phase” as the result of an effect is to perform an expedited process that skips everything else that would happen that phase.
* See rule 724, “Ending Turns and Phases.”
