# Definition

**End the Turn** — To “end the turn” as the result of an effect is to perform an expedited process that skips nearly everything else that would happen that turn.[^cr-glossary]

# Rules

* To “end the turn” as the result of an effect is to perform an expedited process that skips nearly everything else that would happen that turn.
* See rule 724, “Ending Turns and Phases.”
