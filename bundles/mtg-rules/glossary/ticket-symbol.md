# Definition

**Ticket Symbol** — The ticket symbol {TK} with no numbers in it represents one ticket counter.[^cr-glossary]

# Rules

* The ticket symbol {TK} with no numbers in it represents one ticket counter.
* The ticket symbol with a number in it represents a ticket cost.
