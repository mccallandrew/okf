# Definition

**Last Known Information** — Information about an object that’s no longer in the zone it’s expected to be in, or information about a player who’s no longer in the game.[^cr-glossary]

# Rules

* Information about an object that’s no longer in the zone it’s expected to be in, or information about a player who’s no longer in the game.
* This information captures that object’s last existence in that zone or that player’s last existence in the game.
