# Definition

**Food Token** — A Food token is a colorless artifact token with “{2}, {T}, Sacrifice this token: You gain 3 life.” For more information about predefined tokens, see rule 111.10.[^cr-glossary]

# Rules

* A Food token is a colorless artifact token with “{2}, {T}, Sacrifice this token: You gain 3 life.” For more information about predefined tokens, see rule 111.10.
* For Mirrodin! A keyword ability that creates a 2/2 red Rebel creature token and then attaches the Equipment with the ability to that token.
