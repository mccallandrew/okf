# Definition

**Expansion Symbol** — A card’s expansion symbol is a small icon normally printed below the right edge of the illustration that has no effect on game play.[^cr-glossary]

* A card’s expansion symbol is a small icon normally printed below the right edge of the illustration that has no effect on game play.
