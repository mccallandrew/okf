# Definition

**Connive** — A keyword action that causes a player to draw a card, discard a card, and then to put a +1/+1 counter on a creature if a nonland card was discarded this way.[^cr-glossary]

# Rules

* A keyword action that causes a player to draw a card, discard a card, and then to put a +1/+1 counter on a creature if a nonland card was discarded this way.
* See rule 701.50, “Connive.”
