# Definition

**Miracle** — Miracle is a static ability linked to a triggered ability.[^cr-702-94]

# Rules

* Miracle is a static ability linked to a triggered ability.
* (See rule 603.11.) “Miracle [cost]” means “You may reveal this card from your hand as you draw it if it’s the first card you’ve drawn this turn.
* When you reveal this card this way, you may cast it by paying [cost] rather than its mana cost.”
