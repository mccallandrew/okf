# Definition

**Provoke** — Provoke is a triggered ability.[^cr-702-39]

# Rules

* Provoke is a triggered ability.
* “Provoke” means “Whenever this creature attacks, you may choose to have target creature defending player controls block this creature this combat if able.
* If you do, untap that creature.”
