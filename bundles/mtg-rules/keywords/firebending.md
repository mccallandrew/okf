# Definition

**Firebending** — Firebending is a triggered ability.[^cr-702-189]

# Rules

* Firebending is a triggered ability.
* “Firebending N” means “Whenever this creature attacks, add N {R}.
* Until end of combat, you don’t lose this mana as steps and phases end.”
