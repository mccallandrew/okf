# Definition

**Squad** — Squad is a keyword that represents two linked abilities.[^cr-702-157]

# Rules

* Squad is a keyword that represents two linked abilities.
* The first is a static ability that functions while the creature spell with squad is on the stack.
* The second is a triggered ability that functions when the creature with squad enters the battlefield.
