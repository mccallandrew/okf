# Definition

**Craft** — Craft represents an activated ability.[^cr-702-167]

# Rules

* Craft represents an activated ability.
* It is written as “Craft with [materials] [cost],” where [materials] is a description of one or more objects.
* It means “[Cost], Exile this permanent, Exile [materials] from among permanents you control and/or cards in your graveyard: Return this card to the battlefield transformed under its owner’s control.
