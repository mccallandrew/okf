# Definition

**Amplify** — Amplify is a static ability.[^cr-702-38]

# Rules

* Amplify is a static ability.
* “Amplify N” means “As this object enters, reveal any number of cards from your hand that share a creature type with it.
* This permanent enters with N +1/+1 counters on it for each card revealed this way.
