# Definition

**Poisonous** — Poisonous is a triggered ability.[^cr-702-70]

# Rules

* Poisonous is a triggered ability.
* “Poisonous N” means “Whenever this creature deals combat damage to a player, that player gets N poison counters.” (For information about poison counters, see rule 104.3d.)
