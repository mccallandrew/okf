# Definition

**Persist** — Persist is a triggered ability.[^cr-702-79]

# Rules

* Persist is a triggered ability.
* “Persist” means “When this permanent is put into a graveyard from the battlefield, if it had no -1/-1 counters on it, return it to the battlefield under its owner’s control with a -1/-1 counter on it.”
