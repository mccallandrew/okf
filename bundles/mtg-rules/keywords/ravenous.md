# Definition

**Ravenous** — Ravenous is a keyword found on some creature cards with {X} in their mana cost.[^cr-702-156]

# Rules

* Ravenous is a keyword found on some creature cards with {X} in their mana cost.
* Ravenous represents both a replacement effect and a triggered ability.
* “Ravenous” means “This permanent enters with X +1/+1 counters on it” and “When this permanent enters, if X is 5 or more, draw a card.” See rule 107.3m.
