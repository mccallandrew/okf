# Definition

**Battle Cry** — Battle cry is a triggered ability.[^cr-702-91]

# Rules

* Battle cry is a triggered ability.
* “Battle cry” means “Whenever this creature attacks, each other attacking creature gets +1/+0 until end of turn.”
