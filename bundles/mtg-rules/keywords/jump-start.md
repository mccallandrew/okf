# Definition

**Jump-Start** — Jump-start appears on some instants and sorceries.[^cr-702-133]

# Rules

* Jump-start appears on some instants and sorceries.
* It represents two static abilities: one that functions while the card is in a player’s graveyard and another that functions while the card is on the stack.
