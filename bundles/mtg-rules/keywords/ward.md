# Definition

**Ward** is a triggered ability. Ward [cost] means: whenever this permanent becomes the target of a spell or ability an opponent controls, [counter](/keywords/actions/counter-spell.md) that spell or ability unless that player pays [cost].[^cr-702-21]

# Rules

* Ward triggers only against opponents' targeted spells and abilities, not your own.
* If the ward cost includes an X whose value is defined, that value is determined as the ability resolves.
* Paying the ward cost does not change the original spell or ability's targets; it only prevents the counter.
* Nontargeted effects ignore ward.
