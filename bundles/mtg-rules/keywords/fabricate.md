# Definition

**Fabricate** — Fabricate is a triggered ability.[^cr-702-123]

# Rules

* Fabricate is a triggered ability.
* “Fabricate N” means “When this permanent enters, you may put N +1/+1 counters on it.
* If you don’t, create N 1/1 colorless Servo artifact creature tokens.”
