# Definition

**Devour** — Devour is a static ability.[^cr-702-82]

# Rules

* Devour is a static ability.
* “Devour N” means “As this object enters, you may sacrifice any number of creatures.
* This permanent enters with N +1/+1 counters on it for each creature sacrificed this way.”
