# Definition

**Start Your Engines!** — Start your engines! is a static ability.[^cr-702-179]

# Rules

* Start your engines! is a static ability.
* If a player controls a permanent with start your engines! and that player has no speed, their speed becomes 1.
* This is a state-based action.
