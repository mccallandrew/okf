# Definition

**Wither** — Wither is a static ability.[^cr-702-80]

# Rules

* Wither is a static ability.
* Damage dealt to a creature by a source with wither isn’t marked on that creature.
* Rather, it causes that source’s controller to put that many -1/-1 counters on that creature.
