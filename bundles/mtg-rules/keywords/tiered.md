# Definition

**Tiered** — Tiered is a static ability found on some modal spells (see rule 700.2) that applies while the spell is on the stack.[^cr-702-183]

# Rules

* Tiered is a static ability found on some modal spells (see rule 700.2) that applies while the spell is on the stack.
* Tiered means “Choose one.
* As an additional cost to cast this spell, pay the cost associated with that mode.”
