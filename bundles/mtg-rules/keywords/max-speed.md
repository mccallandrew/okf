# Definition

**Max Speed** — A max speed ability is a special kind of static ability.[^cr-702-178]

# Rules

* A max speed ability is a special kind of static ability.
* “Max speed — [Ability]” means “As long as your speed is 4, this object has ‘[Ability].’” See rule 702.179, “Start Your Engines!”
