# Definition

**Embalm** — Embalm is an activated ability that functions while the card with embalm is in a graveyard.[^cr-702-128]

# Rules

* Embalm is an activated ability that functions while the card with embalm is in a graveyard.
* “Embalm [cost]” means “[Cost], Exile this card from your graveyard: Create a token that’s a copy of this card, except it’s white, it has no mana cost, and it’s a Zombie in addition to its other types.
* Activate only as a sorcery.”
