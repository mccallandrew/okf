# Definition

**Enchant** is a static ability written "Enchant [object or player]." It restricts what an Aura spell can [target](/stack-and-priority/targets.md) and what the Aura can enchant.[^cr-702-5]

# Rules

* As an Aura spell is cast, its target must match the enchant ability.
* On the battlefield, the Aura can only be attached to a legal enchant object or player.
* If an Aura has multiple enchant abilities, all restrictions apply together.
* Auras that enchant a player target and attach to players, not permanents.
