# Definition

**Menace** is an evasion ability. A creature with menace can't be blocked except by two or more creatures.[^cr-702-111]

# Rules

* A single creature cannot legally block a menacing attacker by itself.
* Other evasion (such as [flying](/keywords/flying.md)) still applies; blockers must satisfy all restrictions.
* Multiple instances of menace on the same creature are redundant.
