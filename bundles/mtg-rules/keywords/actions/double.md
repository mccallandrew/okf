# Definition

**Double** — Doubling a creature’s power and/or toughness creates a continuous effect.[^cr-701-10]

# Rules

* Doubling a creature’s power and/or toughness creates a continuous effect.
* This effect modifies that creature’s power and/or toughness but doesn’t set those characteristics to a specific value.
* See rule 613.4c.
