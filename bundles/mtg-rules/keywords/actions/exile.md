# Definition

To **exile** an object is to move it to the [exile](/zones/exile.md) zone from wherever it is.[^cr-701-13]

# Rules

* Exile is not destruction; [indestructible](/keywords/indestructible.md) does not stop exile.
* Exiled objects are face up by default unless instructed otherwise.
* Tokens that would be exiled cease to exist (they leave the battlefield and then cease to exist as a state-based action / token rule).
* Distinct from the zone concept itself: this keyword action is the verb that moves objects there.
