# Definition

**Meld** — Meld is a keyword action that appears in an ability on one card in a meld pair.[^cr-701-42]

# Rules

* Meld is a keyword action that appears in an ability on one card in a meld pair.
* To meld the two cards in a meld pair, put them onto the battlefield with their back faces up and combined.
* The resulting permanent is a single object represented by two cards.
