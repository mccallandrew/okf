# Definition

**Transform** — To transform a permanent, turn it over so that its other face is up.[^cr-701-27]

# Rules

* To transform a permanent, turn it over so that its other face is up.
* Only permanents represented by double-faced tokens and double-faced cards can transform.
* (See rule 712, “Double-Faced Cards.”)
