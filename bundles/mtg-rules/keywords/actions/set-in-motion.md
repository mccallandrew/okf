# Definition

**Set in Motion** — Only a scheme card may be set in motion, and only during an Archenemy game.[^cr-701-32]

# Rules

* Only a scheme card may be set in motion, and only during an Archenemy game.
* Only the archenemy may set a scheme card in motion.
* See rule 314, “Schemes,” and rule 904, “Archenemy.”
