# Definition

To **create** tokens means put the specified number of tokens with the specified characteristics onto the battlefield.[^cr-701-7]

# Rules

* Replacement effects that apply to creating a token apply before continuous effects that would modify that token's characteristics.
* Replacement effects that apply to a token entering the battlefield apply after those continuous effects.
* Older cards that said "put [tokens] onto the battlefield" have Oracle text that uses "create."
