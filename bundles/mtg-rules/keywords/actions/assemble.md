# Definition

**Assemble** — Assemble is a keyword action in the Unstable set that puts Contraptions onto the battlefield.[^cr-701-45]

# Rules

* Assemble is a keyword action in the Unstable set that puts Contraptions onto the battlefield.
* Outside of silver-bordered cards, only one card (Steamflogger Boss) refers to assembling a Contraption.
* Cards and mechanics from the Unstable set aren’t included in these rules.
