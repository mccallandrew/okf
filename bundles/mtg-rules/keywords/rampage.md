# Definition

**Rampage** — Rampage is a triggered ability.[^cr-702-23]

# Rules

* Rampage is a triggered ability.
* “Rampage N” means “Whenever this creature becomes blocked, it gets +N/+N until end of turn for each creature blocking it beyond the first.” (See rule 509, “Declare Blockers Step.”)
