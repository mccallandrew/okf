# Definition

**Storm** — Storm is a triggered ability that functions on the stack.[^cr-702-40]

# Rules

* Storm is a triggered ability that functions on the stack.
* “Storm” means “When you cast this spell, copy it for each other spell that was cast before it this turn.
* If the spell has any targets, you may choose new targets for any of the copies.”
