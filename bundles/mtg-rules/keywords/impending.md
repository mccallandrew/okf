# Definition

**Impending** — Impending is a keyword that represents four abilities.[^cr-702-176]

# Rules

* Impending is a keyword that represents four abilities.
* The first is a static ability that functions while the spell with impending is on the stack.
* The second is static ability that creates a replacement effect that may apply to the permanent with impending as it enters the battlefield from the stack.
