# Definition

**Sunburst** — Sunburst is a static ability that functions as an object is entering the battlefield.[^cr-702-44]

# Rules

* Sunburst is a static ability that functions as an object is entering the battlefield.
* “Sunburst” means “If this object is entering as a creature, ignoring any type-changing effects that would affect it, it enters with a +1/+1 counter on it for each color of mana spent to cast it.
* Otherwise, it enters with a charge counter on it for each color of mana spent to cast it.”
