# Activated

Oracle tags under **Activated** (`synergy/activated`).

* [Activated](overview.md) - Activated abilities as a class.
* [Activate From Command Zone](activate-from-command-zone.md) - Scryfall oracle tag: activate from command zone.
* [Activate From Exile](activate-from-exile.md) - Abilities that can be activated from exile.
* [Activate From Graveyard](activate-from-graveyard.md) - Abilities that can be activated from inside a graveyard.
* [Activate From Hand](activate-from-hand.md) - Activated abilities that can be activated from your hand.
* [Activate From Stack](activate-from-stack.md) - Abilities that can be activated from an object on the stack.
* [Activated Ability](activated-ability.md) - Cards with activated abilities.
* [Any Player Ability](any-player-ability.md) - Abilities that can be activated by anyone.
* [Exhaust](exhaust.md) - Abilities that you can only activate once.
* [Ninjutsu](ninjutsu.md) - Collection tag used to apply the various tags that comprise the keyword Ninjutsu. Should be 1-1 with kw:ninjutsu.
* [Pseudo-Cycling](pseudo-cycling.md) - Scryfall oracle tag: pseudo-cycling.
* [Renew](renew.md) - Exile this card from your graveyard: Do a thing. Doesn't need to be the specific Renew keyword, just cards that have an ability to exile themselves in the graveyard.
