# Tap

Oracle tags under **Tap** (`permanent/tap`).

* [Tap](overview.md) - Tapping, untapping, freeze, and lockdown.
* [Etb-Untapper](etb-untapper.md) - Cards that make things enter the battlefield untapped.
* [Freeze](freeze.md) - A permanent doesn't untap during its next N untap steps. For effects that prevent untapping indefinitely, see [lockdown](lockdown).
* [Freeze-Artifact](freeze-artifact.md) - Scryfall oracle tag: freeze-artifact.
* [Freeze-Creature](freeze-creature.md) - Prevent a creature from untapping for its next N untaps. For effects that prevent untapping indefinitely, see [lockdown](lockdown-creature).
* [Freeze-Land](freeze-land.md) - Scryfall oracle tag: freeze-land.
* [Freeze-Nonland](freeze-nonland.md) - Scryfall oracle tag: freeze-nonland.
* [Freeze-Permanent-Any](freeze-permanent-any.md) - Freeze/stun effects that work against permanents of all types.
* [Gives Convoke](gives-convoke.md) - Scryfall oracle tag: gives convoke.
* [Gives Outlast](gives-outlast.md) - Scryfall oracle tag: gives outlast.
* [Lockdown](lockdown.md) - A permanent stays tapped. Named in the Color Pie 2017 article. See also [freeze](freeze).
* [Lockdown-Artifact](lockdown-artifact.md) - Scryfall oracle tag: lockdown-artifact.
* [Lockdown-Creature](lockdown-creature.md) - Scryfall oracle tag: lockdown-creature.
* [Lockdown-Land](lockdown-land.md) - Scryfall oracle tag: lockdown-land.
* [Lockdown-Nonland](lockdown-nonland.md) - Scryfall oracle tag: lockdown-nonland.
* [Lockdown-Permanent](lockdown-permanent.md) - Scryfall oracle tag: lockdown-permanent.
* [Lockdown-Planeswalker](lockdown-planeswalker.md) - Scryfall oracle tag: lockdown-planeswalker.
* [Orochi Ability](orochi-ability.md) - Freeze creatures with combat damage. This ability was used on Orochi in Kamigawa.
* [Tap Fuel-Creature](tap-fuel-creature.md) - Tap a creature to pay for/activate an effect
* [Tap Fuel-Power](tap-fuel-power.md) - Scryfall oracle tag: tap fuel-power.
* [Tap Outlet](tap-outlet.md) - Cards that allow you to tap another permanent as part of an ability cost.
* [Tapper](tapper.md) - Tap down permanents. For cards that tap stuff as a cost, see [tap outlet](tap-outlet).
* [Tapper-Artifact](tapper-artifact.md) - Scryfall oracle tag: tapper-artifact.
