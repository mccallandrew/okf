# Blink

Oracle tags under **Blink** (`permanent/blink`).

* [Blink](overview.md) - Short exile-and-return (flicker) for ETB reuse. Not haven-style long storage and not banish.
* [Flicker](flicker.md) - Exile a card then return it to the battlefield (now or soon).
* [Flicker-Artifact](flicker-artifact.md) - Scryfall oracle tag: flicker-artifact.
* [Flicker-Creature](flicker-creature.md) - Scryfall oracle tag: flicker-creature.
* [Flicker-Enchantment](flicker-enchantment.md) - Scryfall oracle tag: flicker-enchantment.
* [Flicker-Land](flicker-land.md) - Scryfall oracle tag: flicker-land.
* [Flicker-Nonenchantment](flicker-nonenchantment.md) - Scryfall oracle tag: flicker-nonenchantment.
* [Flicker-Nonland](flicker-nonland.md) - Flicker effects that work on all permanent types other than land.
* [Flicker-Permanent](flicker-permanent.md) - Flicker effects that work on all permanent types: artifact, creature, enchantment, land, planeswalker, and battle.
* [Flicker-Planeswalker](flicker-planeswalker.md) - Scryfall oracle tag: flicker-planeswalker.
* [Flicker-Self](flicker-self.md) - Scryfall oracle tag: flicker-self.
* [Flicker-Slow](flicker-slow.md) - Exile a card to be brought back after a set time (usually at end of turn).
* [Flicker-Vehicle](flicker-vehicle.md) - Scryfall oracle tag: flicker-vehicle.
