# Combat Manipulation

Oracle tags under **Combat Manipulation** (`combat/combat-manipulation`).

* [Combat Manipulation](overview.md) - Altering combat steps, blockers, or combat rules.
* [Block Additional](block-additional.md) - Block additional creatures beyond just the one.
* [Block Unlimited](block-unlimited.md) - Block an unlimited, or practically unlimited, number of creatures.
* [Block When Tapped](block-when-tapped.md) - Scryfall oracle tag: block when tapped.
* [Block Without Creature](block-without-creature.md) - These cards make something be blocked ... without anything actually doing the blocking.
* [Combat Arbiter](combat-arbiter.md) - Cards that limit how many can attack and/or block in some way.
* [Combat Manipulation](combat-manipulation.md) - Scryfall oracle tag: combat manipulation.
* [Control Attacker](control-attacker.md) - Scryfall oracle tag: control attacker.
* [Control Blocker](control-blocker.md) - Scryfall oracle tag: control blocker.
* [Force Attacker](force-attacker.md) - Scryfall oracle tag: force attacker.
* [Force Blocker](force-blocker.md) - Scryfall oracle tag: force blocker.
* [Lure](lure.md) - All creatures able to block this creature must do so. See also [lure-limited](lure-limited) and [provoke lite](provoke-lite).
* [Lure-Limited](lure-limited.md) - This creature must be blocked, but not necessarily by all creatures like a true lure.
* [Provoke Lite](provoke-lite.md) - "That creature must block this one this combat if able." It's like Provoke, but without the untapping. Also similar to [lure](lure) and [lure-limited](lure-limited).
