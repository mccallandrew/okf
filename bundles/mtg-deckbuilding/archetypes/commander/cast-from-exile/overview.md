# Definition

Some use the term paradox for the mechanic of the same name introduced in _Doctor Who_. While the mechanic itself is pretty general, there now exist quite a few cards that reward players for casting spells from zones other than their hands, usually from exile.[^draftsim-edh-arch]

# How it wins

Impulse, plot, and exile-cast engines that play from exile.

# Typical packages

These make for very popular cards, with some notable commanders being Prosper, Tome-Bound, Faldorn, Dread Wolf Herald, and Vega, the Watcher. The _Paradox Power_ precon is a perfect showcase of just how many different mechanics in Magic work with this type of strategy.

# Example decks

* [The Thirteenth Doctor Cast-from-Exile](thirteenth-doctor-exile.md) — Exile-cast / paradox-style engines playing from exile.

# Failure modes

Unfocused theme dilution; missing interaction or mana; polarizing plans without table buy-in.
