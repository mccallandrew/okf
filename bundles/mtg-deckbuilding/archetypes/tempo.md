# Definition

**Tempo** decks apply an early clock while using cheap interaction to answer only what would stop that clock. They blend aggro pressure with selective control.[^flores-beatdown]

Distinct from the strategy concept [Tempo](/foundations/tempo.md), which is the resource; this archetype is a list shape built around that resource.

# List shape

* Low-to-mid curve threats; interaction that leaves mana up.[^wiz-curve]
* Card selection (cantrips) to find the mix of threat and answer.
* Few pure late-game bombs—games should end before true inevitability wars.

# Failure modes

* Running out of threats after answering everything.
* Over-answering and falling off the clock.
* Soft mana bases that miss colors for early interaction.
