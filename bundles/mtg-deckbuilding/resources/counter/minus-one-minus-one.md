# Definition

**-1/-1 counters** reduce power/toughness. They are a resource for wither/infect-style boards, modular artifacts that move them, and [Mm Counters Matter](/effects/permanent/modify/mm-counters-matter.md) payoffs—and a liability when piled on your own creatures.

# Deckbuilding notes

* Persist creatures enter with a -1/-1; removing it (or using +1/+1 to cancel) is part of the engine.
* Moving -1/-1 onto opponents’ creatures is removal-adjacent board control.
