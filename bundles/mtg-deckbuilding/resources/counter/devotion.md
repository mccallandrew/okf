# Definition

**Devotion** is a **derived** resource: the number of mana symbols of a color among permanents you control. It is not a stored counter, but decks treat the count like one—scaling creatures, drainers, and cost reduction.

# Deckbuilding notes

* Maximize pips on permanents (creatures, enchantments, gods) rather than instants that leave no devotion.
* Board wipes collapse devotion; rebuild plans matter.
* Related cost patterns: [Affinity For Devotion](/effects/resource/mana/affinity-for-devotion.md), [Colored Mana](/resources/mana/colored-mana.md).
* Distinct from [Energy](/resources/counter/energy.md) / [Experience](/resources/counter/experience.md), which are actual counters on players.
