# Overview

The [official Magic rules hub](https://magic.wizards.com/en/rules) links Comprehensive Rules PDFs, format information, and related policy documents. Use it for authoritative construction constraints (deck size, sideboard, banned lists pointers).

Deep rules concepts live in the sibling [mtg-rules](../../mtg-rules/) bundle; this Resource is the external entry point.

# When to use it

* Confirm format deck-construction rules before a tournament or league.
* Download the current Comprehensive Rules PDF.
* Find links into tournament documents (MTR is out of scope for this deckbuilding bundle).
