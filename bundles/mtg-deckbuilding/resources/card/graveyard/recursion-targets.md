# Definition

**Recursion targets** are yard cards you built to get back—regrowth loops, reanimation bombs, crucible lands. The resource is reusable value across zones.

# Deckbuilding notes

* Separate one-shot flashback spells from persistent engines that return repeatedly.
* [Restock](/effects/zone/graveyard-to-hand/restock.md) returns cards to library instead of hand—different reuse pattern.
