# Definition

**Graveyard size** is how many cards are in the yard. Thresholds, delirium, delve, escape, and “if there are N cards” payoffs care about the count, not only specific cards.

# Deckbuilding notes

* Self-mill and loot inflate size quickly; restock and exile hate shrink it.
* Delve and [graveyard fuel](/resources/card/graveyard/graveyard-fuel.md) spend size as a cost—oversizing can be required.
* Symmetrical mill grows both yards; know which side benefits.
