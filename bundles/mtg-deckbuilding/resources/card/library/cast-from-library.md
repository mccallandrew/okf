# Definition

**Cast from library** (including play-from-top) uses library cards without first drawing them into hand. The library becomes a quasi-hand for as long as the permission lasts.

# Deckbuilding notes

* Pairs with top manipulation so the castable card is the one you want.
* Distinct from tutoring to hand—interaction windows and timing differ.
* Effect inventory: [Cast From Nonhand](/effects/spell/cast-from-nonhand/), [Castable From Library](/effects/spell/cast-from-nonhand/castable-from-library.md), [Play From Top](/effects/spell/cast-from-nonhand/play-from-top.md).
