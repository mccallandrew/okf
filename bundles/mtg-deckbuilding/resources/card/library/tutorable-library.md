# Definition

A **tutorable library** is the deck viewed as a set of roles you can fetch on demand. The resource is not random depth but *addressable* cards via [Tutoring](/resources/card/tutoring.md).

# Deckbuilding notes

* Build tutor targets as packages (lands, answers, win cons) rather than singleton pet cards without fetch density.
* Shuffle tutors randomize the top; combine with top manipulation when sequencing matters.
* Effect hub: [Search](/effects/zone/search/). Related dig patterns: [Consult](/effects/resource/cards/consult.md), [Seek](/effects/resource/cards/seek.md).
