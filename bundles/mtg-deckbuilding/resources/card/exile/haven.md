# Definition

**Haven** effects exile your permanents (or cards) to return them later—storing value through wraths, combat, or timing. Closely related: [purgatory](/effects/zone/exile/purgatory.md) death-storage.

# Deckbuilding notes

* Used as protection and as blink-adjacent value; timing the return is part of the resource.
* Not the same as short [flicker](/effects/permanent/blink/) loops—haven is delayed storage.
* Effect tags: [Haven](/effects/zone/exile/haven.md), [Purgatory](/effects/zone/exile/purgatory.md).
