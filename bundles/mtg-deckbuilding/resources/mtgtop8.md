# Overview

[MTGTop8](https://mtgtop8.com) collects Top 8 and event decklists, useful for seeing which lists convert in paper and online events.

# When to use it

* Validate that a “meta deck” is actually winning events, not only streaming.
* Spot configuration differences (numbers, flex slots) across successful pilots.
* Sample sideboards against a known field.
