# Overview

[Archidekt](https://archidekt.com) is a list builder with category views, playtest draws, and strong Commander workflows. Public decks contribute to EDHREC’s dataset.

# When to use it

* Organize a 100-card list by ramp / draw / interaction / wincons.
* Share a brew or iterate with category budgets visible.
* Export or sync with other tools in a Commander-focused pipeline.
