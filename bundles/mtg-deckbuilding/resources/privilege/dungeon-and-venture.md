# Definition

**Dungeon and venture** progression is a privilege-shaped resource: venture moves you through dungeon rooms for incremental rewards, and completing a dungeon is a payoff spike. Related to—but distinct from—holding the [initiative](/resources/privilege/initiative.md), which *causes* ventures.

# Deckbuilding notes

* Venture without initiative still advances dungeons; initiative makes ventures free each upkeep.
* Choose dungeon based on deck needs (card selection, removal, mana, wincon rooms).
* Sparse dedicated otags—search Scryfall for venture / dungeon; initiative tag: [Take The Initiative](/effects/zone/library/take-the-initiative.md).
