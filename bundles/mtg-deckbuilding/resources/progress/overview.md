# Definition

**Progress** measures how close you are to winning (or an opponent is to losing)—clocks you advance. Distinct from [Life](/resources/life/) as a buffer you hold, and from [Card](/resources/card/) as zone access.

Main clocks in this branch:

* [Damage](/resources/progress/damage.md) (with [combat](/resources/progress/combat-damage.md) / [noncombat](/resources/progress/noncombat-damage.md) satellites)
* [Poison](/resources/progress/poison.md)
* [Commander Damage](/resources/progress/commander-damage.md) — **Commander/EDH-format specific** (also under [Life](/resources/life/commander-damage.md))
* [Mill To Deck](/resources/progress/mill-to-deck.md)
* [Alternate Win Conditions](/resources/progress/alternate-win-conditions.md)

| In progress | Elsewhere |
|-------------|-----------|
| Damage dealt toward lethal | Life total as buffer → [Life](/resources/life/) |
| Poison race | Poison as counters → [Counter → Poison](/resources/counter/poison-counters.md) |
| Commander damage (EDH) | Life framing + commander zone → [Life](/resources/life/commander-damage.md), [Commander Zone](/resources/privilege/commander-zone.md) |
| Mill to empty library | Library as card fuel → [Library](/resources/card/library/) |
| Alternate wins | Effect inventory → [Win Condition](/effects/game/win-condition/) |

# Deckbuilding notes

* Pick a primary clock; splitting damage, poison, and mill without payoffs for each dilutes closes.
* Multiplayer: progress against one opponent is not progress against the table—plan how you finish.
* [Rad](/resources/privilege/rad-counters.md) mills and drains but is not treated as a dedicated win clock here.
