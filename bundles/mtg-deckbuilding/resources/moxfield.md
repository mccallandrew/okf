# Overview

[Moxfield](https://moxfield.com) supports Constructed and Commander lists, primers, collection binding, and playtest / goldfish features. Public Commander decks feed EDHREC.

# When to use it

* Build and share across formats in one account.
* Goldfish opening hands while iterating on curve and mana.
* Publish primers alongside lists for teammates or a playgroup.
