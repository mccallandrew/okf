# Definition

A **spell on the stack** is the temporary object created when you cast a card (or copy a spell). Opponents can interact with it; you and others can [copy](/resources/spell/copies.md) it; [counterspells](/effects/spell/counter/) remove it.

# Deckbuilding notes

* Stack tricks (split second, uncounterable, holding priority) protect this resource.
* Modal and X spells make stack representation matter for copies and redirects.
* Effect hubs: [Counter](/effects/spell/counter/), [Copy-Spell](/effects/spell/copy/copy-spell.md).
