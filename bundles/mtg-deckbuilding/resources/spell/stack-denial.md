# Definition

**Stack denial** treats the opponent’s [spell on the stack](/resources/spell/spell-on-stack.md) as a resource you destroy—counterspells, permission, and related stack interaction. Virtual spell advantage.

# Deckbuilding notes

* Count interaction density vs proactive spells for the format; Commander permission packages differ from 60-card counters.
* Soft counters, taxing counters, and ability counters are different tools—see [Spell → Counter](/effects/spell/counter/).
* Uncounterable and split second blunt this resource.
