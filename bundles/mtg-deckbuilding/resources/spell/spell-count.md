# Definition

**Spell count** is the number of spells cast in a relevant window (this turn, this game, among instants/sorceries). It is the numeric resource behind [storm](/resources/spell/storm.md), magecraft, prowess, and similar payoffs.

# Deckbuilding notes

* Build density: low-MV spells, free spells, and copies that are cast (or storm copies) depending on the payoff’s wording.
* Distinguish “cast” vs “copy” carefully—some payoffs care only about casts.
* Hate: [Hate-Storm](/effects/interaction/hate/hate-storm.md). Payoffs: [Magecraft](/effects/synergy/triggered/magecraft.md), [Gives Prowess](/effects/synergy/triggered/gives-prowess.md), [Gives Storm](/effects/spell/copy/gives-storm.md).
