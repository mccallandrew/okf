# Definition

**Mana sinks** are repeatable effects you can dump substantial mana into each turn—activated abilities, X spells that scale, and similar. [Bottomless mana sinks](/effects/resource/mana/bottomless-mana-sink.md) can win if arbitrary mana is available.

# Deckbuilding notes

* Ramp without sinks floods; sinks without ramp sit inert—build both sides.
* Prefer sinks that advance the plan (draw, create threats, remove) over vanity activations.
* Instant-speed sinks use opponent end steps; sorcery-speed sinks need protected main phases.
* Effect inventory: [Mana Sink](/effects/resource/mana/mana-sink.md), [Bottomless Mana Sink](/effects/resource/mana/bottomless-mana-sink.md).
