# Definition

**Mana** is the primary currency for casting spells and activating many abilities. In this taxonomy it covers what mana *is* (colored, colorless, snow, Phyrexian), how decks *produce* it (lands, rocks, dorks, Treasure, rituals), how they *accelerate* it (ramp, land ramp, multipliers), how they *spend less* of it (cost reduction, alternative costs), and how they *sink* surplus.

This branch is **not**:

* **[Mana](/mana/) construction** — curves, land counts, and pip distribution for building the list.
* **[Energy](/resources/counter/energy.md)** — a separate player counter resource that is often confused with mana but is not mana.
* **[Resource Effects → Mana](/effects/resource/mana/)** — the oracle-tag inventory of effects that change mana availability (this tree links *to* those tags).

# Deckbuilding notes

* Separate **persistent** mana (lands, rocks, dorks) from **burst** mana (rituals, combat mana, Treasure spent the turn you make it).
* Color requirements live in construction ([Colored Sources](/mana/colored-sources.md), [Pip Distribution](/mana/pip-distribution.md)); this branch describes the resource those numbers serve.
* Extra [land drops](/resources/privilege/land-drop.md) accelerate mana without counting as ramp spells; link them from land-ramp strategies.
