# Definition

**Treasure** tokens are artifact tokens that usually sacrifice for mana. Full mana-resource notes live under [Treasure](/resources/mana/treasure.md); here they are board objects that count as artifacts and fodder.

# Deckbuilding notes

* Count for affinity/improvise while they last; spending them is the point.
* Effect/hate: [Hate-Treasure](/effects/interaction/hate/hate-treasure.md).
