# Definition

**Junk** tokens are Treasure-like artifacts that sacrifice for mana (often colorless). Treat them as burst mana board objects—see [Treasure](/resources/mana/treasure.md).

# Deckbuilding notes

* Colorless-only junk fixes less than Treasure; still counts as an artifact permanent.
* Effect tags: [Repeatable Junk](/effects/resource/cards/repeatable-junk.md) when present as a production pattern.
