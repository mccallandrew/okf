# Overview

EDHREC essay on bracket mismatch: many “misrepresented” decks are ecosystem- and expectation-errors rather than intentional pubstomping, and brackets still need flexible post-game adjustment.[^edhrec-power]

Complements the official bracket announcement with lived social heuristics.

# Key takeaways

* Old 1–10 power talk was ecosystem-relative; brackets add structure but still encode **intent and vibes**, not a solved ranking.
* Bracket checklists describe a **floor** for certain strategies—synergy and resilience can still overshoot a claimed band.
* Heuristic: consistently winning **>~33%** (or dominating a claimed band) suggests the deck is too strong for that band; aim roughly **25–30%** in a balanced pod.
* Pre- and **post-game** Rule 0: discuss whether a win was nuts vs typical; ask for a weaker list next game when needed.
* Preview key pieces/strategies so experienced players can calibrate expectations; mystery lasts one game.
* Stronger pilots should sometimes play weaker decks; balancing the *experience* matters more than defending a label.
