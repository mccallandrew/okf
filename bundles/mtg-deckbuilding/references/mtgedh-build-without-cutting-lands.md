# Overview

MTG EDH build guide centered on resisting “cut lands for cool cards”: lock a win plan and table plan, fill a functional **99-card skeleton**, then add theme flex.[^mtgedh-skeleton]

Emphasizes turn mapping, tapland discipline, and one-change-at-a-time tuning.

# Key takeaways

* A deck is a **plan** with a theme as flavor—start with 1–2 win paths and balanced enablers vs payoffs (avoid 12 payoffs / 4 enablers).
* Default skeleton: **37 lands**, **10 ramp**, **10 draw**, **10 interaction**, **7 win cards**; fill remaining slots with theme/flex.
* If the commander already draws/ramps/removes, trim that category slightly—do not delete the floor; commanders die constantly.
* Cut lands only with numbers (low curve + real ramp + testing), not vibes; watch tapland density and color fixing.
* Split interaction: targeted (incl. artifact/enchantment), wipes, protection, plus at least one graveyard hate piece.
* Map turns 1–2 / 3–5 / 6+; goldfish, note one failure sentence per loss, change one axis at a time.
