# Overview

EDHREC guide on building a functional Commander deck: essential card categories with approximate counts, then mana curve and **turn mapping** so the list plays the way you intend.[^edhrec-build]

Uses EDHREC commander pages and Archidekt as practical tooling around the plan.

# Key takeaways

* Start with **win conditions** (roughly seven or more paths), then support casting and protecting them.
* Starting ranges: **8–12 ramp**, **8–10 card velocity**, **8–10 interaction** (including some wraths), **36–38 lands** (more for expensive commanders).
* Assign each card a **primary role**; multi-role cards free slots for finishers.
* After drafting the 99, check the curve and map spells to the turn you expect to cast them (not only printed CMC).
* Recursion, tutors, and hate pieces are secondary packages—add intentionally as power and playgroup demand.
