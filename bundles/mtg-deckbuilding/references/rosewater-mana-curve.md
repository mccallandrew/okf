# Overview

Making Magic column placing the **mana curve** in historical context: early Pro Tour technology around redundancy, making land drops, and tapping mana every turn. Useful for why “curve” became vocabulary, not as a complete modern build guide.[^mm-curve]

# Key takeaways

* Cheap spells let you use early land drops; expensive-only decks waste early turns.
* “Tap as much mana as you can” is a useful default model, not an absolute rule.
* Curve thinking treats similar casting costs as a collective resource, not only as unique cards.
